AI做的神秘LuaIDE，为迷你世界开发了一些功能。

呃，总之这里只教授你基本的操作和指令，其他的你自己翻代码研究去吧。

### 操作
首先，启动软件。
1. 根据所有*.py文件，把需要的库pip install下来
2. 双击IDE.bat
3. 快捷方式没用

然后吧有个键位：Ctrl+I，呼出插件ID插入窗口。

### 指令

new [file/dir]
del [file]
re [file] [name] 其实可以用来复制和移动什么的
back [file]
aback [file] [0/1] 自动备份
tab [block/file] 自动TAB
minidev_help 获得帮助

不建议食用makelua指令
